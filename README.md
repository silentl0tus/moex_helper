## 💡 Что это?

**MOEX Robo-Advisor** — это open-source инструмент для частного инвестора на российском фондовом рынке.
Загружаете выгрузку портфеля из **Snowball Income** или **Izi-Invest** (JSON / Excel / CSV) — и за секунды получаете:

- Комплексный рейтинг **Health Score** для каждой бумаги в портфеле и на рынке;
- Рекомендации робо-эдвайзера: что **продать**, что **купить**, как **ребалансировать**;
- Визуальную **карту рынка**, сентимент-анализ толпы и макро-контекст.

Всё работает в браузере, данные обновляются автоматически через GitHub Actions, деплой — в один клик на Streamlit Cloud.

## 🚀 Основные возможности

### 💼 Аудит портфеля
- Импорт из **Snowball Income** (JSON), **Izi-Invest** и ручных таблиц (Excel / CSV).
- Расчёт бумажного PnL (прибыль/убыток), долей и текущей стоимости позиций.
- Автоматическая классификация: акции, облигации/кэш (резервы), заблокированные фонды (FinEx).

### 🏆 Рейтинг Health Score
- Мультифакторная модель оценки «здоровья» бизнеса (подробнее — [ниже](#-как-работает-health-score)).
- Учёт рентабельности, долговой нагрузки, роста выручки, дивидендной безопасности, инфляционного радара и технического тренда.
- Секторная корректировка: отдельные формулы для **банков** (P/BV × ROE), **холдингов** (P/BV), **IT** (рост вместо дивов), **нефтяников** (цена Urals), **сталеваров** (HRC) и **золотодобытчиков**.

### 📈 Технический анализ
- RSI (14), SMA-50 и SMA-200 для каждого тикера.
- Статусы тренда: 📈 Аптренд, 🚀 Разворот, ⚠️ Коррекция, 📉 Даунтренд.
- Детекция перекупленности (RSI > 75) и перепроданности (RSI < 30).

### 🕰️ Инвестиционные Часы (Макро-ротация)
- Четыре фазы экономического цикла: **Рефляция → Восстановление → Перегрев → Стагфляция**.
- Автоматическая ротация секторных бонусов и штрафов в зависимости от выбранной фазы.

### 💬 Анализ сентимента
- Парсинг форума **Smart-Lab** и **Тинькофф Пульс** для каждого тикера.
- Лексический анализ: позитивные / негативные / аналитические слова.
- Экстрактивная суммаризация: ключевые тезисы из обсуждений.
- Влияние на итоговый Health Score: позитив → бонус, негатив → штраф.

### 🗺️ Карта рынка
- Scatter-диаграмма (Altair): ось X — P/E (оценка), ось Y — ROE (эффективность).
- Размер точки пропорционален Health Score, цвет — принадлежность к портфелю.

### ⚖️ Ребалансировка
- Автоматическое построение целевого портфеля из топ-N бумаг по Health Score.
- Настраиваемые лимиты: макс. доля одной бумаги, число активов, размер капитала.
- Макро-правила: доля кэша и облигаций зависит от уровня IMOEX.

## 🧮 Как работает Health Score?

**Health Score** — комплексный мультифакторный рейтинг «здоровья» бизнеса. Стартует с расчётной базы и проходит через каскад мультипликаторов:

### Базовая формула

```
Health Score = (ROE / P_E) / (1 + Debt_EBITDA) × Growth_Multiplier
```

> **Исключения:** Банки оцениваются по `ROE / (P_BV × 5)`, Холдинги — по `3.0 / P_BV`, IT — с нормированным ROE (мин. 30%).

### Каскад мультипликаторов

| №  | Фактор                      | Бонус                                     | Штраф                                       |
|----|-----------------------------|--------------------------------------------|----------------------------------------------|
| 1  | Макро-контекст сырья        | Нефть Urals > $75 → ×1.2 для нефтяников   | Urals < $60 → ×0.8                          |
| 2  | Цикл стали (HRC)            | HRC > $1000 → ×1.15 для сталеваров        | HRC < $700 → ×0.85                          |
| 3  | Золото (COMEX)              | Gold > $3500 → ×1.2 для золотодобытчиков   | Gold < $2500 → ×0.8                         |
| 4  | FCF Yield (Cash is King)    | FCF > 10% → ×1.2                          | FCF < 0% → ×0.7 (сжигают кэш)               |
| 5  | Дивидендная доходность      | Div > 9% → ×1.20                          | Div = 0% → ×0.85 (IT — исключение)          |
| 6  | Сентимент SmartLab           | Позитив → до +5%                           | Негатив → до −5%                            |
| 7  | Безрисковая ставка (Ключевая)| —                                          | ROE или E/P < Key Rate → ×0.7              |
| 8  | Защита от квазиоблигаций    | Здоровый баланс + рост → дивидендный бонус | Payout > 100% → ×0.8, стагнация → штраф    |
| 9  | Инфляционный радар           | Div обгоняет инфляцию → 🛡️ «Защитник»      | ROE и Div ниже инфляции → 🔥 «Сжигатель»    |
| 10 | Инвестиционные Часы          | Целевой сектор фазы → ×1.15–1.20          | Штрафной сектор фазы → ×0.80–0.90          |
| 11 | Технический тренд (SMA/RSI) | 🚀 Разворот → ×1.2, 📈 Аптренд → ×1.1     | 📉 Даунтренд → ×0.7, RSI > 75 → ×0.8      |

> **Итог:** Компании с Health Score **< 1.0** — кандидаты на продажу. Лидеры рынка уходят **выше 1.5**.

## 🛠 Установка и Запуск

### Системные требования
- **Python** 3.10 или выше
- **pip** (менеджер пакетов)

### Локальный запуск

```bash
# 1. Клонируйте репозиторий
git clone git@github.com:silentl0tus/moex_helper.git
cd moex_helper

# 2. Создайте виртуальное окружение
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate         # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите дашборд
streamlit run streamlit_project.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

### Обновление данных вручную

```bash
# Обновить фундаментальные данные (парсинг Smart-Lab)
pip install lxml html5lib beautifulsoup4
python fetch_fundamentals.py

# Обновить сентимент (парсинг Smart-Lab + Тинькофф Пульс)
python sentiment_scraper.py
```

## ☁️ Деплой на Streamlit Community Cloud

1. Форкните или загрузите проект в свой GitHub-репозиторий.
2. Перейдите на **[share.streamlit.io](https://share.streamlit.io/)** и войдите через GitHub.
3. Нажмите **New App** → укажите репозиторий, ветку `main` и путь к `streamlit_project.py`.
4. Через 2–3 минуты дашборд будет доступен по уникальной ссылке 24/7.

> **Важно:** фундаментальные данные и сентимент обновляются автоматически через GitHub Actions и коммитятся в `fundamentals_cache.csv` / `sentiment.json`. Streamlit Cloud подхватит изменения при следующем перезапуске (обычно — мгновенно).

## ⚙️ GitHub Actions (CI/CD)

Проект использует два автоматических воркфлоу:

### 🔄 Update Fundamentals Cache
- **Расписание:** каждый будний день в 09:00 МСК (06:00 UTC)
- **Что делает:** запускает `fetch_fundamentals.py`, парсит ~55 тикеров с Smart-Lab, обновляет `fundamentals_cache.csv` и коммитит в репозиторий.
- **Ручной запуск:** GitHub → Actions → Update Fundamentals Cache → Run workflow.

### 🔄 Update Sentiment Cache
- **Расписание:** каждые 2 часа в торговое время (10:00–22:00 МСК, будни); один раз утром в выходные.
- **Что делает:** запускает `sentiment_scraper.py`, собирает сентимент по всем ликвидным тикерам MOEX, обновляет `sentiment.json` и коммитит.
- **Ручной запуск:** GitHub → Actions → Update Sentiment Cache → Run workflow.

## 🔌 Источники данных

|---------------------------|--------------------------------------------|---------------------------|
| **MOEX ISS API**          | Котировки TQBR, обороты, эшелоны, свечи    | REST API (без ключа)      |
