# MOEX Robo-Advisor & Portfolio Dashboard

Продвинутый аналитический дашборд на базе **Streamlit** для автоматизированного аудита портфеля, фундаментального и технического анализа акций Московской Биржи (MOEX).

Дашборд позволяет загружать выгрузки вашего портфеля, рассчитывать комплексный математический рейтинг здоровья активов (**Health Score**) и получать автоматические рекомендации к покупке или продаже бумаг на основе текущей макроэкономической ситуации.

## 🚀 Основной функционал

- **Аудит портфеля (JSON / Excel / CSV):** Бесшовная интеграция с экспортами из сервисов **Snowball Income** и **Izi-Invest**. Алгоритм автоматически рассчитывает бумажную прибыль (PnL) и долю кэша/облигаций/заблокированных фондов.
- **Алгоритм Health Score:** Комплексный рейтинг, оценивающий:
  - Рентабельность и недооценку (ROE, P/E, Рост выручки)
  - Дивидендную безопасность (FCF > Div Yield)
  - Долговую нагрузку (Debt/EBITDA) и Риск банкротства
  - Инфляционный радар (определение "Сжигателей" и "Защитников" капитала)
- **Технический Анализ:** Автоматический расчет RSI и трендов (пробои SMA-50 и SMA-200). Выявление "Падающих ножей" и восходящих трендов.
- **Инвестиционные Часы (Макро-ротация):** Подстройка рекомендаций и рейтингов акций под текущую фазу экономики (Рефляция, Восстановление, Перегрев, Стагфляция).
- **Интеграция со SmartLab:** Сбор фундаментальных метрик (P/E, P/BV, Debt, ROE) и анализ сентимента (настроений толпы) напрямую с форума.
- **Интеграция с MOEX ISS API:** Получение котировок в реальном времени, фильтрация по эшелонам (1 и 2) и отбраковка низколиквидных активов.

## 🛠 Установка и Запуск

### Локальный запуск
Убедитесь, что у вас установлен Python 3.10 или выше.

```bash
# 1. Склонируйте репозиторий
git clone <url-вашего-репозитория>
cd moex_helper

# 2. Создайте виртуальное окружение и активируйте его
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите дашборд
streamlit run streamlit_project.py
```
Приложение откроется в браузере по адресу `http://localhost:8501`.

### Деплой на Streamlit Community Cloud (Рекомендуется)
1. Загрузите файлы `streamlit_project.py` и `requirements.txt` в GitHub-репозиторий.
2. Перейдите на [share.streamlit.io](https://share.streamlit.io/) и войдите через GitHub.
3. Создайте новое приложение (New App), укажите ваш репозиторий и путь к `streamlit_project.py`.
4. Через пару минут дашборд будет доступен в интернете 24/7 по уникальной ссылке.

## 📊 Как работает Health Score?

Это математическая модель "Глубокой стоимости" (Deep Value). Рейтинг акции стартует с базовой отметки **1.0** и умножается на бонусы или штрафы в зависимости от качества бизнеса:
- **Бонусы:** Высокий ROE, низкий P/E, дивиденды, покрытые кэшем, перепроданность, защитный статус против инфляции.
- **Штрафы:** Отрицательная реальная доходность (ниже инфляции), зашкаливающий Долг/EBITDA, падающий тренд.

Компании с Health Score `< 1.0` классифицируются как мусор или кандидаты на продажу. Компании с рейтингом `> 1.5` — флагманы рынка.
